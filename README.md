# Student Dashboard

A simple student dashboard built using HTML and JavaScript. This project calculates student marks, averages, grades, rankings, and displays student reports using JavaScript array methods.

## Features

- Display all student records.
- Calculate total marks and average.
- Assign grades based on average marks.
- Filter passed and failed students.
- Calculate class and subject averages.
- Find the class topper.
- Sort students by total marks and display rankings.
- Display student data in an HTML table.
- Convert report data into JSON using `JSON.stringify()`.
- Parse JSON input using `JSON.parse()` and handle errors with `try...catch`.

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `dashboard/index.html` in your browser.
4. Use the buttons to view all students, passed students, and rankings.
5. Test JSON input using the JSON textarea.
